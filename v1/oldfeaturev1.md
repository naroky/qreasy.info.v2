# QREASY.INFO Version 1 — ฟีเจอร์ที่สำรวจพบ

- เว็บไซต์ที่สำรวจ: <https://www.qreasy.info/>
- วันที่สำรวจ: 19 ตุลาคม 2026
- ขอบเขต: หน้าเว็บสาธารณะที่เข้าถึงได้โดยไม่เข้าสู่ระบบ

เอกสารนี้บันทึกสิ่งที่พบจากหน้าเว็บและ HTML ที่ให้บริการจริง โดยแยกพฤติกรรมที่ยังยืนยันไม่ได้ไว้ท้ายเอกสาร เพื่อใช้เป็นข้อมูลตั้งต้นสำหรับ QREASY.INFO Version 2

## ฟีเจอร์สำหรับผู้ใช้

### 1. สร้าง QR Code จาก URL

- หน้าแรกมีฟอร์มสำหรับใส่ URL เพื่อสร้าง QR Code
- ช่องกรอกเป็นข้อความ มี placeholder `Enter URL...` และระบุป้ายกำกับ `URL`
- ปุ่ม `Generate` ส่งฟอร์มด้วย HTTP POST ไปยังเส้นทาง `createqr`
- หน้าเว็บระบุว่าบริการสร้าง QR Code Image
- มีข้อความตรวจสอบในฟอร์มว่า URL เป็นข้อมูลที่จำเป็น

### 2. ตรวจสอบ CAPTCHA ก่อนส่งคำขอ

- ฟอร์มแสดง Google reCAPTCHA พร้อมข้อความ “I'm not a robot”
- ผู้ใช้ต้องผ่าน CAPTCHA เพื่อส่งคำขอสร้าง QR Code

### 3. ใช้งานเมนูนำทางแบบย่อ

- โลโก้/ชื่อ `QREASY.INFO` ลิงก์กลับหน้าแรก
- เมนูมีรายการ `Static Qr Code` ซึ่งลิงก์กลับหน้าแรก
- บนหน้าจอขนาดเล็กมีปุ่ม `Menu` สำหรับเปิด/ปิดเมนูนำทาง

## เนื้อหาและส่วนประกอบของหน้า

- ส่วนหัวแสดงชื่อ `QREASY.INFO` ไอคอน QR Code และคำโปรย “Web Service for simple generate QR Code Image”
- หน้าฟอร์มมีหัวข้อ “Input Your URL for generate QR Code Image”
- มีพื้นที่โฆษณาจาก Google AdSense ในหน้า
- ใช้รูปแบบหน้าเว็บจาก Bootstrap/Start Bootstrap Freelancer พร้อม Google Fonts และ Font Awesome
- หน้าเว็บมีการโหลด Google Analytics เพื่อวัดการใช้งาน
- มี favicon ของเว็บไซต์

## สิ่งที่พบว่าไม่มีหรือไม่ปรากฏในหน้าเว็บ

- ไม่พบการเข้าสู่ระบบ บัญชีผู้ใช้ หรือประวัติ QR Code
- ไม่พบตัวเลือกปรับแต่ง QR Code เช่น สี ขนาด โลโก้ หรือรูปแบบไฟล์
- ไม่พบเมนูดาวน์โหลด/แชร์ QR Code ในหน้าแรกก่อนส่งฟอร์ม
- ไม่พบเมนู About หรือ Contact ที่เปิดใช้งานอยู่ (รายการดังกล่าวอยู่ใน HTML แต่ถูกคอมเมนต์ไว้)
- ไม่พบหน้าเอกสาร API, robots.txt หรือ sitemap.xml ที่ URL มาตรฐานขณะสำรวจ

## ข้อจำกัดของหลักฐาน

- ไม่ได้ส่งฟอร์มสร้าง QR Code เพราะต้องผ่าน reCAPTCHA จึงยังยืนยันไม่ได้ว่าหน้าผลลัพธ์มีรูป QR Code ปุ่มดาวน์โหลด หรือรูปแบบการตอบกลับอย่างไร
- การเปิด `https://www.qreasy.info/createqr` โดยตรงถูกเปลี่ยนเส้นทางกลับหน้าแรก จึงไม่สามารถยืนยันรายละเอียดของผลลัพธ์จากการสร้างได้
- ไม่มีข้อมูลยืนยันเรื่องชนิด URL ที่ยอมรับ การตรวจสอบ URL ฝั่งเซิร์ฟเวอร์ ขนาด/ความละเอียดของภาพ ระยะเวลาเก็บข้อมูล หรือข้อจำกัดการใช้งาน
- คำว่า “Static” ปรากฏเป็นชื่อรายการเมนูเท่านั้น ยังไม่มีหลักฐานพอจะสรุปพฤติกรรมเพิ่มเติม เช่น QR Code เป็นแบบคงที่ในเชิงเทคนิคหรือไม่

## สรุปสำหรับการวางแผน Version 2

ความสามารถหลักที่ยืนยันได้ของ Version 1 คือ **กรอก URL → ผ่าน reCAPTCHA → ส่งคำขอสร้าง QR Code Image** ส่วนการแสดงผลหลังสร้างและการดาวน์โหลดยังต้องทดสอบเพิ่มเติมจากระบบต้นทางหรือยืนยันจากเจ้าของผลิตภัณฑ์ก่อนนำไปกำหนดเป็นพฤติกรรมเดิมที่ Version 2 ต้องรักษาไว้
